## 2. 何を推定したか

同じ水分と接種源で育てた**単独栽培の平均種別バイオマス**を基準に、二種混植における各種の重量変化を対数比で定義：

`C(i,pair,soil,water)=log(mean_mixed_biomass(i)/mean_mono_biomass(i))`

さらに同じ混植・水分の**滅菌MIX土壌**に対する各生土壌接種の追加的な効果：

`D=C(i,pair,live_soil,water)−C(i,pair,sterile_S,water)`

3ペア×2構成種×2水分×5土壌＝**60 C**。そのうち生土壌4条件と滅菌Sとの差＝**48 D**。処理済み行ではなく**混植鉢ごとに2種を同じ再標本化単位**にし、条件別3–4鉢と単独鉢を10,000回ブートストラップ。グループごとの単独対照の再標本化を、複数の混植比較で共有している。

**注意：** 単独と混植での初期密度や生育空間を元論文の設計から完全には監査できていない。したがって C を「競争係数」や「真の1個体当たり抑制」と呼ばず、「同じ土壌条件の単独栽培に対する、混植下の種別重量応答」と呼ぶ。**Dry vs Wetは到着順序操作ではない。** 生接種源と滅菌MIXの差は、微生物だけでなく栄養塩や滅菌による化学変化も含み得る。

## 3. 確認された実データ結果

### 3a. 土壌による応答の強さの変化

すべてのCが負（**60/60**）だったが、これを単純に競争抑制だと断定してはならない。個々の植物が混植中で利用できる空間・初期種密度なども影響する。

同じ2種混植・同じ種・同じ水分に固定しても、5種類の接種土壌の間で C の最大値と最小値が離れた。12（3ペア×2焦点種×2水分）の比較では、対数比の**土壌間レンジが約0.14〜1.32**。

特に：
- **SK–AF, AF（湿潤）：** Cの土壌間レンジ **1.316**、乾燥でも **1.318**。
- **SK–AF, SK（湿潤）：** 0.843、乾燥 0.650。
- **SK–AC, SK（乾燥）：** 0.912、湿潤 0.327。

生土壌と滅菌土壌を比較する48 Dのうち、**29は負、19は正**。10,000個体/鉢単位ブートストラップの**未補正**95%区間がゼロを含まないものは**10/48**（負7、正3）。これは**48個の独立研究でも、48個の多重比較補正済みの検定でもない**。4鉢（1条件だけ3鉢）の探索的レンジとして示し、普遍性を主張しない。

例：
- **SK–AF混植のAFに、AF由来土壌（Wet）：** D=**−0.932**、95%区間 **[−1.351,−0.436]**。
- **SK–AF混植のSKに、混合由来土壌（Wet）：** D=**−0.843**、区間 **[−1.516,−0.182]**。
- **SK–AC混植のSKに、AF由来土壌（Dry）：** D=**+0.528**、区間 **[+0.053,+0.993]**。

環境依存を直接表す `D(Dry)−D(Wet)` の24探索的対照では、未補正95%区間がゼロを含まない正方向の例が3件、他21件はゼロを含む。環境による効果の交互作用の一般性を示すには足りない。

### 3b. 優勢種の順位は大きくは動かない

各2種混植で最終平均**生バイオマス**が多い種を10の水分×土壌文脈について比較すると：

| 混植ペア | SKが多い条件 | AFが多い条件 | ACが多い条件 |
|---|---:|---:|---:|
| SK–AF | **9/10** | **1/10** | — |
| AF–AC | — | 0/10 | **10/10** |
| SK–AC | 0/10 | — | **10/10** |

SK–AFで例外となるのは **Wet×MIX**。平均生重量 SK=**0.5183g**、AF=**0.7814g**。同一混植鉢の2種を同時に再標本化すると、10,000回のブートストラップでSK＞AFとなる割合は**6%**だった。これは一部の環境で勝者が入れ替わることと整合するが、**たった4鉢**、選択後の比較である。

AF–ACとSK–ACではACが10文脈すべてで最終重量上の優勢種。これは他種より高い*競争適応度*を保証しない。比較しているのは植付け密度を調整した種内増殖率ではなく、**混植後の絶対平均重量**である。

## 4. KNK独自の価値と未解決点

この実データ再解析が示す最も使いやすい研究上の対比は、**土壌環境の履歴に対応した混植の種別重量応答が変動しても、どちらの種が最も多いかは多くの場合変わらない**という現象である。ただし、生物間相互作用の強さを直接推定してはいない。さらに出典Zenodoの原著概要自体が土壌微生物と競争・共存を扱っており、これをKNKの新規発見として再包装しない。

KNKの構造保持研究との関連は新しい統合仮説である：

> 「到着・土壌の履歴が相互作用の量的な強さに反映しても、優勢種の対応関係や存在量順位に必ず同じようには現れない。履歴がどの状態変数に見えるかは、相互作用から群集構造への変換条件に依存する。」

しかし本実験は、群集の**到着順序**を操作していないし、隣接種を除く相互作用の分解も完全でない。最終のバイオマス順位や土壌Cに履歴が見られたことを、直接的な因果ネットワークの形成の証明にはできない。

**さらに重要な独立性制約：** 2023年Zenodoと2024年Jing Dryadは同じ研究グループ・重なり合う植物種・土壌5条件・乾燥処理を扱う。**サンプルの重複・原稿の版関係は未検証**。本実験を2024年とは別の独立研究としてメタ解析の研究数に加えない。2024年Dryad原Excelは、公開APIのファイルダウンロードが401・HTML検証ページで止まったため再採点していない。

## 5. 探索的拡張の次の判別実験

同じ実験で、土壌接種履歴（滅菌、先住種由来、混合由来）×生きた先住個体の有無×混植における初期密度×乾燥を交差させ、一定の後着種齢で絶対重量・資源濃度・根の占有度・植栽密度を反復測定する。

測定する三つの推定対象：
1. **資源/土壌に残った環境的効果**：先住個体を除去しても後着種の成長を変えるか。
2. **生きた競争相手による追加効果**：同じ土壌、同じ初期密度で先住個体を残すことで、さらに成長が変わるか。
3. **相互作用から群集構造へ**：その効果で多種群集の種組成・名前なし順位・総バイオマスのどれが変わるか。

これを同じ試験系で行うまでは、Deloryの根探索量差、van Steijnの年齢一致隣接種効果、今回のJing系土壌混植応答を因果的な一本の鎖として証明したとは言わない。
