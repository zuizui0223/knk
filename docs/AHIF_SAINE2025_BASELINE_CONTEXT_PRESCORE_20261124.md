# Saine — pretreatment state and held-site intervention-response prediction

2026-11-24. Exploratory, specified before these new outcome calculations, after the negative transfer result in run 45388257428. Same 460-log experiment, 446 complete QC logs, 347 treated and 99 controls. Original pinned Zenodo 13819389 RData, 4653 non-target OTU roster. Not new independent evidence.

Question: can baseline community state (rather than inoculum identity alone) predict introduction-associated changes in another forest? Four pre-treatment log-level features fixed in advance: log(1+OTU richness), Simpson concentration, top1 share, log(1+non-target read total). Natural/felled stratum is already part of design. No post-treatment read depth, actual inoculum success, year-1 outcomes from held-out site, or inferred interactions enter features. Features are summaries, not direct competitive coefficients.

Responses: within-log named and sorted TV displacement from 2019 to 2020/2021, primary two representations. Primary training on year-1 observations in 4 sites and testing on year-2 in held-out fifth site. Secondary same-year transfer (training year-2, testing year-2 at held-out site) to separate a little of temporal transfer from geographical transfer; same two endpoints with separate Holm family, not independent studies. No effect comparison across significance.

Use a residualized treatment score R-loss. Let e be observed treated fraction within each retained original site x natural/felled stratum, conditional on the post-QC subset; e is fixed under label permutation. Original stratum weights n_original/460 used in holdout loss: equal weight for logs within each observed stratum after scaling to original strata size. Let W=T-e. Fit nuisance mean m(X) on training sites only, ignoring treatment, separately for each endpoint/year, ridge penalty 1 on standardized baseline features and natural/felled dummy (intercept unpenalized). Regress training Y1−m1(X) on W times natural/felled-specific constant (M1) and W times standardized baseline features (M2), penalize slopes with ridge 1 and leave contextual treatment intercepts unpenalized. Fit M2 jointly, then compare M1 plus alpha*(M2−M1), alpha grid 0,.25,.5,.75,1. Select alpha by inner site holdout minimizing year-2 R-loss on the outer training sites ONLY. Prediction target at outer held site is residualized year-2 observed Y2−m2(X); m2 trained on other sites only and identical for all models. M0 uses tau=0, M1 contextual intercepts, M2 shrunken context-dependent prediction. No heldout outcome enters fit/selection. Report all 5 fold alpha, weighted R-losses and total relative gain vs M1; pooled gain vs M0 descriptive. Also full M2 (alpha 1) stress test. Same-year sensitivity uses year-2 training as well; still heldsite exclusive. Training-site and held-site labels used only in score and effect model, not feature transforms learned from heldsite.

Conditional permutation reference: 999 binary labels shuffled within original retained strata, preserving arm counts. Refit all treatment-response models and inner alpha in every permutation. Nuisance outcome model and baseline transformations do not use labels and can be cached. This is a reference for sharp no binary intervention effect, **not an exact test of no treatment-effect heterogeneity allowing constant nonzero effects**. Two upper-tail tests for positive incremental R-loss gain, Holm within each training-year family. No site fold t-tests. Interpret as a predictive diagnostic, not causal moderator or direct interaction evidence. Conditional complete-case analysis does not guarantee randomization exchangeability. Only 5 fixed sites, original 161 evidence rows unchanged. If negative, prioritize independent experiments instead of adding new endpoints to this dataset.
