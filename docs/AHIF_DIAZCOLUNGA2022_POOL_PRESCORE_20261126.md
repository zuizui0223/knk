## Forward detection endpoint (primary)
For each unordered parent pair i,j, medium, both mixed wells (i,j and j,i) and both focal orientations i as resident/j as partner and reverse; focal orientation analytical only, not temporal arrival order. Pre-parent relative read proportions. Regional roster = taxa detected in any of eight pre-parent profiles in this medium. Risk set taxa in roster undetected in focal pre-parent. Y detected at mixed endpoint; Y_control detection in same focal-parent unmixed propagated endpoint, evaluated on exact same risk set (counterfactual-style diagnostic, not paired randomized control or causal estimate). P = frequency in the six pre-parent profiles excluding both focal and actual partner. D = binary detection in actual partner. Fixed H=(P+D)/2, as PR19. Compute Brier losses P,D,H, and gains P−H, P−D. Primary mean equally over wells and orientations within unordered pair, then pairs, then media. Both real and control target evaluated with same predictions. Report mixed-control differential gain (descriptive). Compare actual chosen donor with six other possible partners' hybrid, each alternative excluded from its own pool, keeping focal and outcome fixed; equal alternatives, no p-values or false independence. Report mismatch Bray-Curtis on normalized original parent profiles and pair-level mean improvement; separate medium Spearman and medium-centered Pearson, plus leave-one-origin-out sensitivity (delete all pairs containing mapped original community ID in both media; one origin may be present in only one). No pairwise iid p-values; complete graph has shared parents and shared controls; two media same source family. Presence is sample detection, not whole-community absence/ancestry. Separate counts and mean gains for risk taxa detected by other six parents (shared pool) vs partner-only (P=0,D=1), with undefined subgroup counts, no cherry-picking. Threshold sensitivity relative abundance >=0.001 in pre/endpoint (fixed, no re-selection based on gain). Report fraction of detected endpoint relative mass outside regional pre-parent roster; these unobserved-source taxa excluded from Brier target, not imputed zero globally. 

## Optional fixed source-disjoint calibration test (predeclared; may STOP if inadequate)
For each held pair, train only on pairwise mixed wells where neither held parent label occurs; exactly 15 unordered training pairs within medium, 30 physical wells, source profiles known. Use fixed smoothed frequency estimator of target taxon detection conditional on actual partner presence (Laplace Beta(1,1) over training risk observations, each unordered training pair contributes at most one mean per taxon and donor-presence stratum; no pooling repeated wells as independent). Compare base taxon detection frequency ignoring donor against conditional on donor detection, using same train risk set, smoothing and targets, no other tuning. For unseen taxon/donor-state, fallback to base estimate; report counts. Source-held evaluation is retrospective, not independent prospective validation. Base and conditional may both use only known pre profiles; training includes no outcome involving either held source. Source profile information across all parents allowed for fixed P but this learned comparison must use only training outcomes; do not interpret as causal establishment probabilities. No formal meta-analysis, no independent study count inflation, frozen prior studies/PR19 intact.
