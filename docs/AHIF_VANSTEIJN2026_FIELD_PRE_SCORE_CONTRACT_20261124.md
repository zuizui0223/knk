## Source grain and faithful processing

The authors' own `Abundance_code.Rmd` reads original `Pinpoint_all_years.csv` as semicolon CSV and applies **`Site!="GAL" & Type=="Transect"`** before all principal species abundance analyses. DO NOT mix `Type=Plot` (other monitoring) or `GAL` samples. This gives **2,832 positive species ×plot-year rows**, **40 persistent independently assigned plots** in `plotdata.csv`: 2 sites `MAL` (Lönnstorp) and `UME` (Röbäcksdalen) ×5 randomized blocks ×4 treatments (one assigned plot per treatment per block). Same **40 plots sampled once in each of four years 2021,2022,2023,2024**, totaling **160 plot-year community states but 40 independent experimental units**, not 160.
- Four source intervention labels from author code: `FtS` = fast first; `StF` = slow first; `SFearly` = together early; `SFlate` = together late. Preserve actual two different synchronous sowing-date treatments, do not collapse them without new plan.
- Original 20 sown species in `speciesinfo.csv`: 10 fast vs 10 slow; 8 grasses/12 forbs, 10 high vs10 low density. Site-year transect source records **76 distinct taxa**, of which 18 are in the 20-sown-species roster (two never found in the source data), and the other 58 are non-target/spon­taneous. **Verify** 76−18=58 before any analysis, and keep these counts source-specific; the original website says two sown taxa were never recorded.
- One row records a positive `Abundance` hit count for a species in a particular plot×year, not biomass. No explicit zeros are archived for species not detected in a surveyed transect. Build a fixed **76-species global union** of all recorded taxon names (true author-coded species names); within each *observed whole-plot×year* community zero-fill only taxon names absent from the recorded-positive transect rows. Do not invent missing plots or replace truly missing `Abundance`.
- Each site-year has exactly **20 whole plots**, five blocks with four distinct assigned treatment labels each; all 40 treatment assignments remain identical across years. Any missing plot/site/year, duplicate species measurement, mismatch with source plot assignment, invalid count, or nonpositive whole-community abundance sum → STOP.

## Prespecified primary statistical representation

For every **site×year state** separately (2×4=**8** repeated snapshots), form each plot's nonnegative 76-taxon **positive pinpoint hit proportions**. Compare:
1. `named76`: global fixed source taxon order (preserve identity);
2. `rank76`: independently sort each plot's exact same 76 proportions descending (erase species labels, preserve dominance geometry).

Both have the same 20 original whole plots, the same 76 counts, same total-normalization and identical dimensionality. Use Bray–Curtis distance and one-way Gower-centered history-treatment pseudo-R². This statistic is a **distance geometry representation, not entropy/information units**.

**Design-respecting randomization:** each site comprises five randomized blocks, each block four original physical plots with precisely one source history label. For each site generate the same **9,999 random block-wise 4-label permutations** (seed 20261124 + site code). **Reuse exactly the same block-wise permuted plot treatment assignments across all four years and both representations** in that site. This preserves persistent plots' correlated repeated observations. Null-calibrated effect `E=R²_observed−median(R²_permuted)`; upper-tail p=(1+#permuted>=observed)/10000. Report each estimate and permutation-null 95% interval for both modes. Correct the **16 primary site-year named/rank p values** by Holm for transparent multiple-snapshot exploration. Do not claim absence where p>0.05; do not infer representation contrast simply because two p-values have different outcomes.

**Primary additional trajectory gate:** within each site concatenate per plot its **four annual normalized 76-taxon vectors** into one 304-column vector and compare to four concatenated within-year sorted 76-rank vectors for the same 20 distinct plots; same original site block-wise assignment permutations. This is **one 4-year profile per plot**, not four independent samples. Report full-trajectory named, sorted E and p for two sites separately; no pooling as independent publications.

## Prespecified secondary checks (not additional independent studies)

- Sown-target 20 original taxa (10 fast +10 slow, including exactly two all-zero archive species) versus full observed 76 taxa. Sort within exactly same 20-name width; if even one plot-year has 0 total sown counts, mark the entire site-year sown-only endpoint as `STOP_ZERO_TARGET_TOTAL` rather than selecting plots.
- Sown fast10 and slow10 separately: within-guild normalized named vs sorted response, **only** when each plot has positive biomass/hit count in that predeclared group; otherwise `STOP_ZERO_GUILD`. This is a guild-conditioned representation; it is not the same 76-column structure nor an independent effect.
- Spontaneous/non-target taxa only, 58 names; if any plot-year has zero non-target counts, mark `STOP_ZERO_NON_TARGET`.
- One-scalar top1 dominance share and total-positive-hit sum scored as univariate Euclidean-distance pseudo-R² with identical blocked assignment permutations. These differ in biological units from the 76-species profile and have descriptive uncertainty only.
- For the overall four-year site profile, report `delta_R2=named_R2−sorted_R2`; source block-cluster bootstrap resampling five whole blocks (each with its four treatments, B=2,000 seed 20261124), reporting a *descriptive conditional* 95% percentile interval. No climate-year causal interpretation and n=5 blocks/site is low.
- Do not select species, taxonomic families or transformations after seeing outcomes for a new "significant" hypothesis. All eight year snapshots and both complete site trajectories must be in the evidence output, including nulls.

## Biological novelty and strict epistemic bounds

The *original* study already established emergence speed, arrival schedule and field-site impacts on priority effects; **those findings are NOT KNK discoveries**. This new-to-KNK reanalysis asks whether **identity-free abundance geometry vs identity-rich composition** carries a different history signature, including temporal persistence, under an actually randomized multi-species field design. Even if robust, it does **not** identify direct time-dependent competition coefficient changes, because the source did not manipulate individual partner absence/root barriers, and it measured pin-hit community abundances rather than individual demographic rates. The existing AHIF novel hypothesis requires the actual interaction mechanism and rank/identity storage to be independently tested *in the same community units*.

**Primary experimental unit:** whole field plot; five blocks per site, 40 total; year is repeated measurement. One original publication cluster, **not 8 independent study effects**. Other van Steijn studies may share authors/field sources; retain lab overlap `LAB_SARNEEL_VANSTEIJN`. No merging this result into frozen KNK v28–v38 or existing Ecology Letters candidate.
