# Independent parent-origin holdout: ReplayEcology 2025

Specified before accessing ASV counts or calculating prediction outcomes. Pascual-García et al. 2025, Nature Communications 16:3002, DOI 10.1038/s41467-025-57591-2. Author repository apascualgarcia/ReplayEcology, exact commit fba177fbae5c51c059cb6075298be9732c6c3aba; first archived release DOI 10.5281/zenodo.13785758. Use author-recommended final processed ASV matrix (NOT raw sequencing reads) and matched metadata, pinned Git blobs. Metadata already inspected via GitHub: 1375 records, 275 distinct parents, each 0D and 7D_rep1–4 exactly once, 14 original collection locations, counts AshridgeEstate 11, BurhamBeeches 32, BeechWood 6, LongWood 11, OldWindsorWood 14, PullingshillWood 21, SilwoodPark 1, StAlbansCity 14, CombeHill 21, WindsorForest 6, GreenbroomCovert 50, WindsorGreatPark 1, WaterersPark 14, WythamWoods 73. Baseline replicate field is not reliable for identification; Experiment field identifies time and final replicate. Ignore 4M and all unmatched samples. Parent and Location labels must match within all five states.

Scientific scope: prior paper already establishes composition-dependent repeatability, initial-state trajectories, attractors and links to function. This is NOT a new demonstration of initial-state dependence. No intervention or independently manipulated newcomer in this dataset. Independent source experiment for spontaneous succession / initial-state prediction, NOT replication of Saine treatment moderation. No source family inflation; related Rivett/Jones/Pascual-Garcia papers may reuse the same original tree-hole samples, maintain overlap group. 

Primary test: Do three identity-free initial-state summaries (log1p ASV richness, Simpson concentration, top1 fraction) improve prediction of mean terminal composition beyond baseline read total? For each parent, use the same fixed whole ASV roster, close each sample independently, average the four independently revived final profiles within parent. For named response average labeled profiles; for rank response sort each profile BEFORE averaging (not rank the mean). Two multivariate terminal outcome families, avoid baseline-to-change mathematical coupling. No rarefaction or depth cutoff beyond source processing; require integer nonnegative counts and positive sample totals for all matched states; otherwise STOP. No outcome-dependent sample removal. Baseline log non-target not appropriate: here all ASVs, no manipulated targets. Read totals are retained processed counts, not cell abundance or true sequencing depth.

Outer leave-one-original-collection-location-out, 14 held locations. Every parent has weight 1. All four final replicates stay together. Training-only standardization of baseline predictors. Fixed ridge penalty 1 on slopes, unpenalized intercept. M0 depth + depth squared; M1 adds three standardized biological summaries. Predict mean final vector; squared Euclidean loss on actual mean terminal vectors. Linear predictions are diagnostic scores, not guaranteed compositional probabilities. Relative held-out SSE gain (SSE0-SSE1)/SSE0. Record per-location loss and leave-one-location-out-of-aggregate sensitivity; no significance test across 14 correlated CV folds. Both representations use identical split and covariates.

Approximate conditional null for gain: fixed observed features, fit reduced outcome linear model with original 14 location intercepts + standardized depth + depth squared, no biological features. HC2 residual scaling, independent parent Rademacher signs shared across both response representations, 999 wild draws. Refit prediction maps logically on each Y* using same fixed predictors; no tuning. High-dimensional outcome Gram trick exactly equivalent to linear fits. Under conditional mean and independent-parent error assumptions this tests extra predictive information relative to this restricted null; not an exact experiment randomization or causal biology. Negative or zero observed gains retained. Two Holm tests. If singleton sites create unit leverage, remove no parents: use HC2 residual scale zero for exactly fitted singleton under restricted design, state singleton contributes no residual uncertainty, sensitivity excluding singleton sites from aggregate descriptive only. If matrix mismatches or source files not available, explicit stop without synthetic outcomes. No pathogen analysis, no culture protocols. Raw authors' files ephemeral in CI; aggregate JSON only. No change to existing 161 effect ledger until source result audited.
