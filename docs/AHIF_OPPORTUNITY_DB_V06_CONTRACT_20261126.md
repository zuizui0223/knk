# AHIF opportunity-to-outcome database v0.6 — frozen build contract
2026-11-26 JST. Parent PR21 8a6eb0511d81d8abc43608b0ed0421561e2073d8. Extend validated v0.5 in separate normalized tables. Do not modify any old study/effect tables or manuscript. Purpose: reusable source-grounded data for community assembly / biotic-interaction opportunity hypotheses, NOT a graph of observed signed interactions. Three distinct endpoint study families (Villarreal, Diaz-Colunga, Goldman), existing observations not three new studies. All original source hashes and primary results must replay before registering. Scope data to study/local marker; no sequence upload, no global taxon-name join, no claim of immigrant ancestry. Store derived candidate-risk records, not raw read/count tables.

Tables:
- opportunity_sources: DOI/source identity, resolution, design, measurement and inference limits.
- opportunity_lanes: unique source+resolution+threshold+proxy. Primary Villarreal raw detection (all 63 author bins), Diaz common233 raw and 0.001, Goldman p15 stock proxy threshold .001 and >0; p3 control proxy sensitivity likewise. All distinct lanes, never independent studies. 
- opportunity_taxa: study-local code (SHA256 of normalized original ID or common marker; name for author zooplankton bins), resolution. No cross-study matching or raw sequences.
- opportunity_events: lane, event ID, focal/partner labels, physical target ID, parent/network dependency group, interval or endpoint, pre/target timing, whether actual transfer, partner nominal volume fraction nullable, evidence class. Diaz two analytical orientations per physical mixed well, Goldman two orientations per physical p5 mixture; not two observations. Villarreal all 20 pairs×4 intervals, explicitly mark pre-transfer placebo; only actual experimental recipient orientation. Preserve source IDs and thresholds. 
- opportunity_risk: event × local taxon at preceding nondetection; pool numerator/denominator, partner detection, source relative abundance, target detected, focal unmixed endpoint detected if measured. Villarreal risk set entire 63-bin roster, pool other 9 donor tanks in same lake; Diaz/Goldman risk set regionally detected but focal absent; pool six other parent profiles, partner excluded. No zero inferred for absent profile; explicit verified roster. Source relative abundance relative sample count or relative read, not absolute propagule size; q nullable except Goldman actual nominal volumetric fraction. Risk rows dependent. For each source/lane replay frozen Brier losses and counts exactly before saving. Goldman's p15 and p3 proxy means are not direct inoculum measures. For Diaz harmonize 238nt parents to first 233 nt per verified audit, preserve unresolved marker IDs; only common233 in this build. Goldman's prior model source-held results remain as previous receipts; fixed models replay from risk rows. 
- opportunity_assays and opportunity_assay_links: separate Diaz isolate co-culture observations (C3/C6, same run/medium as community mixtures). Verify metadata and original OTU hash, 112 off-diagonal co-culture wells plus 16 monocultures (8 per medium), exact well/pair link to C1/C4. Labels ChampionN = isolate originating from CommunityN by author script, NOT necessarily true dominant or species identity. Derived read signature outcomes: TV between pair culture and arithmetic mean of two same-medium monoculture relative-read profiles; unique marker signatures at relative abundance >=.001 in own monoculture, <.001 in other; observed pair fraction of reads in each signature, unresolved remainder; no causal interaction signs or coefficients inferred. Same-medium unmixed control comparison is a descriptive reference. Also record community coalescence vs arithmetic mean of two time-matched unmixed communities, same pair/well. Diagonal/self cultures not primary. No missing profile imputation; require all selected profiles >=1000 reads. Record exact source hashes and code commit. 
- explicit claim level: observed experimental contact assignment; detection outcome; isolated co-culture composition response; actual transfer/establishment and signed per-capita interaction not measured. Never join opportunity records into observed ecological interaction edge table. Signed interaction effects table stays empty unless data have matched absolute population growth or directly observed interaction outcome. 
- SQL views summarize detection by partner availability and exposure status, separately by source/lane; pair-balanced prior Brier replays and derived assay link coverage. All rows meta_eligible=no. Source-level primary summaries distinct from repeated risk events. No pooled effect or iid p values. Exact SQLite integrity, FK, no duplicate primary keys, bounds and source receipt checks. CSV export derived tables only; archive reproducible build, schema and digest, no raw data or full sequence.
