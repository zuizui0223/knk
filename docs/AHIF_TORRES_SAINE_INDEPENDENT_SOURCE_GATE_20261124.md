## Saine et al. fungal independent validation target

Saine et al. (2025), ISME Communications, article ycaf166 (index DOI 10.1093/ismeco/ycaf166; final author PDF uses 10.1093/ismecom/ycaf166, preserve discrepancy until source registry confirms). Author PDF https://web.stanford.edu/~fukamit/Saine-et-al-2025a.pdf, public data DOI 10.5281/zenodo.10959957. Prior article already measured introduction effects on residents and their context-dependence; novelty is NOT this existence result.

Methods source verified: 5 Finnish forest sites, each 55 naturally fallen and 37 artificially felled Picea abies logs. Nine introduced fungal species each randomized to 5 natural and 3 felled logs per site; sterile dowels in 10 natural and 10 felled logs per site. 360 treated + 100 controls, 460 distinct logs. Pooled sawdust per log at pre-treatment 2019 and 2020/2021; 1380 planned sample states. Author QC excludes 11 low-read samples (<10,000 reads before target exclusion); 1369 sample states and 4646 non-target OTUs after removing all nine target species (16 original OTU classifications). Original presence/absence model uses 225 common OTUs; read-count ordination uses Hellinger; richness and estimated DNA quantity separately. Relative reads are neither biomass nor individual organism abundance. Log type is observational context, not a randomized causal factor. The same 460-log experiment appears in earlier Saine papers including Ecology 10.1002/ecy.70013; group conservatively as one source experiment pending ID check. This intervention randomizes introduced species identity, NOT reciprocal arrival order.

Pre-outcome decision: first acquire version-specific public Zenodo metadata and author-file checksums, inspect file format and R source mapping. Do not score until sample ID, log ID, year, site, original randomized treatment assignment, read-depth QC, 16 target OTU exclusion and sampling missingness reconcile. If no nonbinary abundance table, rank architecture is not available. For complete pairs, evaluate log-level before-to-after differences, retaining fixed non-target roster; use site x log type constrained assignment permutations only after original randomization and QC exchangeability verified, never shuffle 1369 sample rows independently. Record QC exclusions by assignment and time; if differential missingness or unknown assignment, stop inferential scoring. Prioritize separately one- and two-year changes, identity and rank, richness and log DNA amount; assess whether initial community context predicts response beyond introduced species identity. Train/test split by whole forest sites, not logs repeated across time. Any estimated partner effect learned from the same outcome cannot be an independent causal mediator. No claims on taxonomic or geographical universality.
