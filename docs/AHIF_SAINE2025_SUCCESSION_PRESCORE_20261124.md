One experiment. 460 logs, 5 sites x 55 naturally fallen (B broken/U uprooted) and 37 felled (R); 9 introduced fungi x 40 and 100 sterile-dowel controls. Randomization at log level within site x natural/felled, NOT individual drill holes or years. Neither log type nor site randomized. Verify original allocation counts: each site/natural group 5 per introduced species plus 10 controls, felled 3 per species plus 10 controls. Full source checks mandatory. RData join by SampleID and OTU names, reorder only exact one-to-one matching keys. Read depth filt_nread >=10000 as authors. Remove all OTUs assigned to the nine target species from every log/time/arm, including naturally present targets; 16 excluded and 4646 retained columns. Exact standardized taxon-name matching, require nine target identities and 16 exclusions, record mapping and original S2 code before score; if mismatch STOP. Non-target = not an experimentally introduced target taxon; not proof all taxa resident at baseline.

Primary fixed balanced longitudinal cohort: logs observed at all three years, authors' QC at each year and positive non-target read totals. Keep explicit missingness/zero roster counts, do not impute. Check treatment-dependent eligibility using all original 460 logs, site x source log-type blocked permutation (10-group plus binary assignment, Holm 2). If either p<=.05 stop complete-case inference, retain coverage and descriptions only. Even if not significant, conditional randomization after filtering is not exact full-cohort ITT; it assumes exchangeability after QC and is an exploratory conditional analysis. Report each arm/stratum attrition. No conditioning on actual colonization success (post-treatment).

Endpoints: within-log 2020 minus 2019 and 2021 minus 2019 signed change in normalized non-target reads at fixed 4646 taxon labels, separately sorted within each log/year. Euclidean geometry (not Bray on signed changes). Site x natural/felled block-centered responses and treatment indicators, partial R² = explained sum of squares / residual total after fixed strata; E = R² minus median of 1999 constrained assignment permutations. Same allocation draws across endpoints/time within a lane. 10-group main family 4 tests (2 years x named/rank) Holm 4. Any inoculation vs sterile controls and identity among 9 inoculated species only: distinct lanes, Holm 4 each. 10-group scalar secondary family 6 tests (2 years x richness, Simpson concentration, top1), Holm 6. Pre-inoculation placebo named/rank test family 2, report regardless; do not treat baseline p as proof of valid randomization. No absolute biomass or DNA output inference from sequencing reads. No comparison of significance as proof of endpoint difference; no new direct mediation. All endpoint estimates and non-significant tests stored in separate aggregate JSON before DB promotion. Later prediction via site-held-out training; independently measured interaction or intervention-derived response features needed, no same-outcome circular model.
