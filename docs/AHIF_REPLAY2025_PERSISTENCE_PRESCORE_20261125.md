# ReplayEcology: initial-profile persistence and representation falsification

2026-11-25 JST. Exploratory follow-up specified before the new scores. Original two hash-pinned author files, exact 275 parents x five states, 14 collection locations, 1454 ASVs, 1100 final replicate endpoints. Prior held-location summary gain rank 11.55%, named .97%, but only versus initial depth. No independent new source or intervention. Original paper https://doi.org/10.1038/s41467-025-57591-2 already establishes initial composition conditioning.

Target: mean four terminal closed profiles, for rank sort each endpoint first then average. Baseline X is initial closed labeled or initial sorted profile, aligned with target in same 1454 columns. Hold out whole original collection locations exactly as prior scorer. All 275 parents retained; same initial counts and original processing; no data-dependent filtering. For every held site, standardize four baseline scalars only on training parents. Fixed ridge penalty 1, intercept unpenalized. Prespecified models:
- Mmean: mean terminal profile on training sites; Mraw: unchanged initial profile (no fitting).
- Mdepth: depth and its square; Msummary: depth, depth², log1p richness, Simpson, top1 (same as prior).
- Mpersist_depth: fit Mdepth to Y and X separately on training data; compute residuals rY and rX in training, gamma=clip(dot(rY,rX)/dot(rX,rX),0,1), 0 if denominator zero. Predict depth Yhat + gamma*(initial X−depth Xhat). Mpersist_summary uses same rule with Msummary. The direct comparison is Mpersist_summary versus Mpersist_depth. This train-only residualized persistence estimate permits ordinary profile carryover. Not a causal autoregressive model; unconstrained regression predictions may be outside simplex. Report all losses, gammas, per-location gains and aggregate gain. Mraw and Mmean avoid overstating forecast value. No clipping/reprojection.

Additional representation diagnostic: common summary baseline Ksummary, rank and named initial Hellinger profile linear kernels each centered using training rows, scaled by training mean diagonal; summary covariates standardized on training rows and kernel scaled likewise. Fit four kernel models: summary, summary+rank, summary+named, summary+rank+named, fixed lambda 1, sensitivity .1 and 10. Intercept trained via response centering. Identical held sites, penalties, terminal targets. Compare rank gain over summary and named gain over summary+rank, for each endpoint. Report all three penalty settings, never choose best on outer heldout. Positive named incremental gain means initial taxonomic labels add predictive information to this rank representation, not direct pairwise interaction. Negative gain may reflect finite sample/regularization. Named profiles contain rank information nonlinearly; this is model-specific, not information-theoretic decomposition.
