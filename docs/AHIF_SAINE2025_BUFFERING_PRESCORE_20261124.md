## Why a direct test is necessary

The previous two-year any-introduction named E=.002368 (Holm .014) and rank E=.002837 (Holm .320). Different significance does NOT demonstrate attenuation: the observed rank E is slightly greater, and response dimensionality/variance differs. No positive structural-buffering conclusion yet.

## Primary paired displacement test

For each complete log, use closed non-target count profiles at baseline and year 1 or 2. Named displacement is total variation (TV) = half L1 between labeled OTU compositions. Rank displacement is the same TV between descending sorted compositions. By rearrangement, rank displacement <= named displacement for each log; this arithmetic inequality is NOT an ecological finding. Define identity-specific excess displacement G = named TV - rank TV. Compare the **treated-minus-sterile-control difference of G**, weighted by original allocation stratum counts (55 natural/37 felled per site). Within each stratum, treatment-minus-control mean; combine fixed preassigned weights n_original/460. Compare named and rank TV shifts and G in the same log. Report 9999 constrained binary label permutations within site x original natural/felled strata, two-sided absolute contrast, six-test Holm across year x outcome (named,rank,G). Stratified treatment-arm log bootstrap 4000 replicates, percentile unadjusted 95% CI for descriptive effect, preserve pairing between named/rank and years. No equivalence conclusion; this tests average displacement magnitude, not the original multivariate centroid effects. Baseline 2019 is pre-introduction, all post-treatment QC caveats retain. Negative G contrast is possible. Never pool with grassland E. If positive G effect with little rank effect, candidate excess taxonomic displacement, not direct compensation/interaction mediation. If not, record no support.

## Depth sensitivity (pre-outcome fixed)

Keep the same fixed 4653 OTU columns, original read QC and complete triplets. Separately retain logs with all three **non-target** read totals >=1000 and >=5000. No pseudocounts, no adaptive threshold. Audit treatment-dependent eligibility across all assigned 460 logs using both 10-label and binary conditional permutation (1999, Holm 2 within each depth). Stop inferential scoring if either adjusted p<=.05, or any source stratum loses one binary arm. Otherwise report conditional inference, acknowledging post-treatment filtering may bias results. At each threshold run 8 fixed-seed multivariate hypergeometric rarefactions without replacement per sample. Retain 3 years and original log IDs. Re-run binary 2-year x 2-representation partial Euclidean R² test with common 1999 assignment draws (average normalized R² across the 8 independent rarefactions before null-centering; no selecting seeds). Also score the identical log subset with original reads, to distinguish subset from rarefaction sensitivity. Holm per 4-test family. For TV endpoints, average per-log displacement over 8 draws and test the same six endpoints with common constrained permutation; do not count rarefactions as replicates. Report per-draw E min/max descriptive. Retain all depth coverage, gate failures, null results. Total read abundance is sequencing effort, not biomass.
