# KNK — Assembly-history ecology

菌類群集・草地群集で、**形成履歴（到着順序）が現在のどの生態学的状態に残るか**を検証する生態学研究リポジトリです。

## 研究の中心

**同じ形成履歴でも、群集組成・優占構造・機能・地下部構造への痕跡の残り方は異なる。** これは2つの独立した公開操作実験の再解析に基づく限定的な実証であり、普遍法則や特定の相互作用機構の同定ではありません。

| 実験 | 強く支持される結果 | 重要な不支持・境界 |
| --- | --- | --- |
| 菌類到着順序 × 宿主植物（233植物・12宿主遺伝子型） | 5菌類の群集組成で履歴保持 E=+0.1467, p=0.0001。順位構造にも E=+0.1486, p=0.0001 | 宿主のさび病病斑率は E=+0.0153, p=0.3893。組成から病徴への因果媒介は未検証 |
| 草地・地上地下（19 rhizobox） | 地上部機能群組成 E=+0.8034, p=0.0001 | 6層根分布 E=+0.0344, p=0.3765。総地上部バイオマスも有意ではない |
| 菌類の履歴別優占構造（同じ233植物の追加解析） | Alternaria対他4履歴：順位1の優占 E=+0.11812, p=0.0002、順位2–5 E=+0.04723, p=0.0316。優占差は12遺伝子型中11型で同方向 | 新しい独立実験ではない。宿主遺伝子型との交互作用 p=0.7548。特定の生理的機構は未同定 |

## 論文・投稿準備

`manuscript/history_storage/` に Ecology Letters向け本文、4図の生成コード、引用監査、カバーレター、投稿準備チェックリストを原文のまま移管しました。研究結果はv38で凍結済み。原資料上は投稿準備済みですが、著者情報・利益相反確認・投稿版DOIの最終確認は未完了で、**投稿済みとは扱いません**。図表生成には `python -m pip install -e '.[figures]'` を利用できます。

## 再現方法

解析はPython 3.10以降を使用します。統計計算の共通コア `eog.history_retention` は [EOG](https://github.com/zuizui0223/eog) の移管前コミット `bd8531144e5ff655334990a664313ebc5e734308` に**固定した依存**として呼び出します。KNKは生態実験の実装・解釈の所有元、EOGは方法論実装の所有元です。

```bash
python -m pip install -e '.[dev]'
python scripts/verify_migration_integrity.py
python -m pytest tests -q
```

元の外部実験データはライセンス・出典・SHAで照合して取得し、ここには再配布しません。旧EOGの成功したActions run / artifact digest / 結果fingerprintは各 `docs/*_result.md` に保持。**移管による再採点・効果量の再調整は行っていません。**

## 範囲

移管元の凍結コミット：[EOG bd8531144e](https://github.com/zuizui0223/eog/tree/bd8531144e5ff655334990a664313ebc5e734308)。数理・手法の統合は引き続きEOGで管理します。
